# Pomodorolist v1.19 — final report (Ranks + Streak leaderboard)

v1.19 is built on top of v1.18 in separate `v1.19: …` commits on `focus-app`. **v1.18 stays deployable on its own**
(live-branch commit `844f9fa`, deploy steps in `notes/v1.18-report.md`). **Deploy v1.18 first**, check it, then v1.19
with the steps below.

## What's new (for users)
- **Ranks, one season per month.** Your counted focus hours this month take you from Bronze through Silver, Gold,
  Platinum and Diamond (three divisions each: III → II → I) to Master and Grandmaster.
- **A head start each new season** from last season's best rank.
- **Season rewards.** The end of a season pays coins and puts a season badge ("Nov 2026 · Diamond III") on the trophy
  shelf.
- **First-time rewards.** The first time you reach a rank you get a cosmetic:
  - Silver and Gold: a frame;
  - Platinum and Diamond: an aura;
  - Master: a poster for Pomeo's room;
  - Grandmaster: an animated frame.
- **Rank-ups mid-block.** A small toast during the focus block, then the full celebration after it ends.
- **Rank badges next to names.** On leaderboard rows and the podium, friend rows, study-session lists and tables, clan
  members and challenge cards. Hidden in True Minimalist.
- **Where you see your rank.**
  - Timer: a compact rank line with a progress bar.
  - Profile: a Rank card with the season, days left, your next step, your placement, last season and the first-time
    rewards.
- **New leaderboards.**
  - **Ranks:** this season's hours.
  - **Streaks:** Current or Best, with the milestone flame.
  - Both have Friends and Global views. A streak that has lapsed drops off the Current board.
- **Demo.** The preview shows all of this with sample data and still writes nothing.

## Bug fixed along the way
- **A pop-up that reopened right after closing could vanish.** Dialogs close with a short (0.17 s) animation, and
  during that time the app still counted them as open.
  - So a new pop-up reusing the same window in that moment got its content swapped in, then closed with the old one.
  - Seen with the Giant-harvest reveal arriving just after the garden tour or a plant window closed.
  - The fix: opening a dialog now cancels a pending close, and every pop-up uses it (16 places).
  - The regression test is in `v116c`.

## The numbers
| Rank | Season hours | Divisions (minutes) |
|---|---|---|
| Bronze | 0–10 | III 0 · II 200 · I 400 |
| Silver | 10–25 | III 600 · II 900 · I 1,200 |
| Gold | 25–50 | III 1,500 · II 2,000 · I 2,500 |
| Platinum | 50–80 | III 3,000 · II 3,600 · I 4,200 |
| Diamond | 80–120 | III 4,800 · II 5,600 · I 6,400 |
| Master | 120–180 | — (7,200) |
| Grandmaster | 180+ | — (10,800) |

**I kept the brief's thresholds.**

| Daily study | Diamond (80 h) | Grandmaster (180 h) |
|---|---|---|
| 3 h | about day 27 | — |
| 6 h | — | on day 30 |

- Grandmaster stays rare: a 30-day month at 6 h a day, every day.
- A serious student always has a division within 3–7 hours.
- Lower thresholds would put most 4–6 h students at Master by mid-month, with nothing left to chase.

**What counts.**
- Only completed focus blocks from the session log count, Finish-early blocks included.
- Minutes are grouped by the UTC day the block ended.
- Each UTC day is capped at **14 h (840 min)**.

**Season = UTC month.** The rules can only check the server clock, so the season key must be the UTC month. In India
a season turns over at **05:30 on the 1st**. The first season is **November 2026**, so there are no rewards for earlier
months.

**Placement (soft reset).**
- Your shown rank is the higher of (rank from this season's hours, floor from last season's peak).
- Floors from last season's peak:

  | Last season's peak | Starts at |
  |---|---|
  | Gold | Bronze I |
  | Platinum | Silver III |
  | Diamond | Silver I |
  | Master | Gold III |
  | Grandmaster | Gold II |
  | Bronze / Silver | no floor |

- The floor lifts only the badge. The Ranks board sorts by this season's hours.

**Season reward (coins).**

| Bronze | Silver | Gold | Platinum | Diamond | Master | Grandmaster |
|---|---|---|---|---|---|---|
| 10 | 40 | 80 | 150 | 250 | 400 | 600 |

- Claimed automatically in the next season, once.
- If two devices claim different peaks, only the highest pays, so it never pays twice.

## New Firestore fields
**`publicStats`: no new fields.** The brief asked for `streak`/`bestStreak` on `publicStats`, and the first build put
the season and streak numbers there. That document's update rule then went over Firestore's limit of 1,000 rule
expressions per request, so the write was refused.

The numbers now live in a small new collection, **`rankStats/{uid}`**. Its fields are all optional for old users; an
app before 1.19 simply has no document and shows no badge.

| Field | Type | Meaning |
|---|---|---|
| `username`, `level`, `tier`, `frame`, `color`, `avatar`, `aura` | as in `publicStats` | the look of a board row |
| `global` | bool | shown on the Global boards (the existing "Show me on the global leaderboard" setting) |
| `seasonKey` | string `YYYY-MM` | the current UTC month |
| `seasonMin` | int | counted minutes this season |
| `prevPeak` | int 0–16 | last season's peak rank (sets the placement floor) |
| `streak` | int | current streak (days) |
| `bestStreak` | int | best streak ever |
| `streakDay` | string `YYYY-MM-DD` | the last day the daily goal was met (readers use it to tell a live streak) |
| `joined` | int (ms) | when the account was created (Firebase Auth metadata) |
| `updatedAt` | timestamp | the server time of the write |

Other notes:
- `publicStats` is back to its v1.18 fields. Its rule was also made cheaper: it computes the time allowance once and
  checks only the changed keys on update. The meaning is unchanged.
- `publicProfiles` is unchanged.
- "Erase all data" also deletes `rankStats`.

## New composite indexes (all on `rankStats`, query scope Collection)
1. `global` Ascending · `seasonKey` Ascending · `seasonMin` Descending: the global Ranks board.
2. `global` Ascending · `streakDay` Ascending · `streak` Descending: the global Current-streak board. It asks only for
   live streaks (`streakDay` = yesterday, today, or ±1 day for time zones), so lapsed streaks can't fill its top 50.
3. `global` Ascending · `bestStreak` Descending: the global Best-streak board.

The Friends boards read each friend's document and need no index.

## Updated `firestore.rules` (summary; the full file is at the end)
**`match /rankStats/{uid}`**
- **get:** yourself, a friend, or anyone when `global == true`, unless blocked.
- **list:** only `global == true` documents.
- **create / update / delete:** the owner only.

**Create**
- A valid document (`validRankStats`).
- `prevPeak == 0`.
- `seasonMin ≤ 240`: deleting and re-creating the document can't jump the season.

**Every write (`validRankStats`)**
- Only the fields above.
- `username` is your registered name.
- The look fields are bounded.
- `updatedAt == request.time`.

**Season (`validSeason` / `seasonGrows`)**
- `seasonKey` must be the current UTC month.
- `seasonMin` is a whole number, `0 ≤ seasonMin ≤ 840 × UTC day of the month`.
- Within a season, it never goes down and grows by at most (minutes since the last write + 240).
- `prevPeak` stays fixed within a season.
- At a new season:
  - `seasonMin` starts within the same allowance;
  - `prevPeak` can't be higher than the rank of the minutes the document held.

**Streak (`validStreak` / `streakGrows`)**
- Whole numbers, with `bestStreak ≥ streak`.
- `bestStreak ≤ days since joined + 2`.
- `joined` is in the past and never changes once published.
- The best never goes down and grows by at most (elapsed days + 2) per write.
- `streakDay` is a real date at most one day ahead of the server. The check now handles month ends, which also fixes
  the other day-key checks on the last day of a month.

**What the rules can't fully verify (no server code)**
- **The minutes themselves.**
  - Rules bound how fast `seasonMin` can grow (real time + 4 h, and 14 h × the day of the month) but can't see the
    focus blocks.
  - Worst case: a tampered client adds about 4 h per write beyond real time, still capped at 14 h a day.
  - A new document starts at ≤ 4 h.
- **`prevPeak` at a season change.** It is bounded by what the document held last season, which was itself bounded.
- **Streaks.**
  - `joined` comes from the client (rules can't read Firebase Auth's creation time), and the first publish is bounded
    only by that.
  - A tampered client can claim an old join date once and then grow its best streak by at most a day or two per day.
  - The current streak may jump up to the best, because an honest device that was offline catches up.
- **A live streak** is judged on read from `streakDay`.
  - A streak shows when its last goal day is today, yesterday, or one day earlier in the viewer's calendar. The
    extra day covers time zones: a friend in another country can be a day behind.
  - So someone who missed yesterday in the same time zone can show for at most one more day.
- **Fixing these properly** needs a Cloud Function that recomputes rank and streak from the session log.

## firestore.rules (exact)

```
rules_version = '2';

// ============================================================================
// Pomodorolist — Firestore security rules
//
// What other people can see lives OUTSIDE users/{uid}:
//   usernames/{name}            { uid }               exact-username lookup only
//   publicProfiles/{uid}        badge, level, flair, streak, hours, join date
//   publicStats/{uid}           focus minutes per period (leaderboards)
//   activity/{uid}              last 12 weeks + last 20 sessions (friends only)
//   presence/{uid}              "focusing now" (friends only)
//   friendships/{a_b}           a request or a friendship between two users
//   inbox/{uid}/items/{id}      kudos and nudges (preset reactions, no text)
//   challenges/{id}             weekly challenges between friends
//   clans/… clanNames/… clanCodes/… clanOf/…   clans, the study-group system (v1.14, see CLANS below; session modes v1.14.2; raid HP table + security audit v1.14.3)
//
// HONEST NOTE ON CHEATING: there is no server here (no Cloud Functions on the
// free plan), so every number is calculated on the user's own device. These
// rules block obvious cheating — impossible jumps, decreasing totals, more
// minutes than real time allows, other people's documents — but a determined
// user could still write believable fake numbers for themselves.
// ============================================================================
service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() { return request.auth != null; }
    function me() { return request.auth.uid; }
    // Usernames are the login: "<username>@pomodorolist.app". This ties every
    // public username to the account that really owns it.
    function myName() { return request.auth.token.email.split('@')[0]; }
    function path(col, id) { return /databases/$(database)/documents/$(col)/$(id); }

    // Accepted friendship between me and uid (document id = smaller uid + "_" + larger uid): one read.
    function friendDoc(a, b) { return path('friendships', a + '_' + b); }
    function pairDoc(uid) { return me() < uid ? friendDoc(me(), uid) : friendDoc(uid, me()); }
    function isFriend(uid) { return exists(pairDoc(uid)) && get(pairDoc(uid)).data.status == 'accepted'; }
    // owner has blocked me
    function blockedBy(owner) { return exists(/databases/$(database)/documents/users/$(owner)/blocked/$(me())); }

    // ---------------- Private data: owner only (unchanged) ----------------
    match /users/{uid} {
      allow read, write: if signedIn() && me() == uid;
      match /{document=**} {
        allow read, write: if signedIn() && me() == uid;   // includes months/ and blocked/
      }
    }

    // ---------------- Username lookup ----------------
    match /usernames/{name} {
      allow get: if signedIn();
      allow list: if false;                                // no browsing all usernames
      allow create: if signedIn()
        && name == myName()
        && request.resource.data.keys().hasOnly(['uid'])
        && request.resource.data.uid == me();
      allow update: if false;
      allow delete: if signedIn() && resource.data.uid == me();
    }

    // ---------------- Public profile ----------------
    match /publicProfiles/{uid} {
      allow get: if signedIn() && (me() == uid || !blockedBy(uid));
      allow list: if false;
      allow create, update: if signedIn() && me() == uid && validProfile();
      allow delete: if signedIn() && me() == uid;
    }
    function validProfile() {
      let d = request.resource.data;
      return d.keys().hasOnly(['username', 'level', 'tier', 'frame', 'color', 'avatar', 'aura', 'clanTag', 'streak', 'longest', 'hours', 'joined', 'big', 'updatedAt'])
        && d.username == myName()
        && validAvatar(d) && validAura(d) && validClanTag(d) && validBig(d)
        && d.level is int && d.level >= 1 && d.level <= 1000
        && d.tier is string && d.tier.size() <= 20
        && d.frame is string && d.frame.size() <= 30
        && d.color is string && d.color.size() <= 30
        && d.streak is int && d.streak >= 0 && d.longest is int && d.longest >= d.streak && d.longest <= 100000
        && d.hours is number && d.hours >= 0 && d.hours <= 60000
        && d.joined is int && d.joined <= request.time.toMillis()
        && d.updatedAt == request.time;
    }

    // Biggest harvest (optional, v1.16): 'species:kg' such as "pumpkin:12.4" — a species id and a weight up to 9999.99.
    function validBig(d) {
      return !('big' in d) || (d.big is string && d.big.size() <= 40 && d.big.matches('^[a-z]{2,20}:[0-9]{1,4}(\\.[0-9]{1,2})?$'));
    }
    // Profile picture id (optional, so older app versions keep working): a short string such as "av_cat".
    function validAvatar(d) {
      return !('avatar' in d) || (d.avatar is string && d.avatar.size() <= 30);
    }
    // Chosen special aura (optional, v1.12+): a short id such as "au_b_dragon_sq". Missing = the streak aura.
    function validAura(d) {
      return !('aura' in d) || (d.aura is string && d.aura.size() <= 30);
    }
    // Clan tag shown next to the name (optional, v1.14): must be the tag of the clan the user is really in.
    function validClanTag(d) {
      return !('clanTag' in d)
        || (resource != null && 'clanTag' in resource.data && resource.data.clanTag == d.clanTag)      // unchanged: no reads
        || (exists(/databases/$(database)/documents/clanOf/$(me()))
            && d.clanTag == get(/databases/$(database)/documents/clans/$(get(/databases/$(database)/documents/clanOf/$(me())).data.clan)).data.tag);
    }

    // ---------------- Leaderboard stats ----------------
    match /publicStats/{uid} {
      allow get: if signedIn() && (me() == uid || ((resource.data.global == true || isFriend(uid)) && !blockedBy(uid)));
      allow list: if signedIn() && resource.data.global == true;   // global leaderboard queries
      allow create: if signedIn() && me() == uid && validStats() && createLimits();
      allow update: if signedIn() && me() == uid && validStats() && updateLimits();
      allow delete: if signedIn() && me() == uid;
    }
    function validStats() {
      let d = request.resource.data;
      // (on an update only the changed keys are checked: the stored document passed this check when it was written,
      //  and checking every key against the list costs too many of the 1,000 expressions a request may use — v1.19)
      return (resource == null ? d.keys() : d.diff(resource.data).affectedKeys()).hasOnly(['username', 'level', 'tier', 'frame', 'color', 'avatar', 'aura', 'clanTag', 'global',
                               'dayKey', 'dayMin', 'weekKey', 'weekMin', 'weekKeySun', 'weekMinSun',
                               'monthKey', 'monthMin', 'lifeMin', 'lastWeekKey', 'lastWeekMin', 'produce', 'harvests', 'updatedAt'])
        && d.username == myName()
        && validAvatar(d) && validAura(d) && validClanTag(d) && validGardenTotals(d)
        && d.global is bool
        && d.level is int && d.level >= 1 && d.level <= 1000
        && d.tier is string && d.tier.size() <= 20 && d.frame is string && d.frame.size() <= 30 && d.color is string && d.color.size() <= 30
        && d.dayKey is string && d.dayKey.size() == 10 && d.weekKey is string && d.weekKey.size() == 10
        && d.weekKeySun is string && d.weekKeySun.size() == 10 && d.monthKey is string && d.monthKey.size() == 7
        && d.lastWeekKey is string && d.lastWeekKey.size() == 10
        && d.dayMin is int && d.dayMin >= 0 && d.dayMin <= 1440
        && d.weekMin is int && d.weekMin >= 0 && d.weekMin <= 10080
        && d.weekMinSun is int && d.weekMinSun >= 0 && d.weekMinSun <= 10080
        && d.monthMin is int && d.monthMin >= 0 && d.monthMin <= 44640
        && d.lastWeekMin is int && d.lastWeekMin >= 0 && d.lastWeekMin <= 10080
        && d.lifeMin is int && d.lifeMin >= 0 && d.lifeMin <= 3600000
        // today is inside this week and this month, and everything is inside the lifetime total
        && d.dayMin <= d.weekMin && d.dayMin <= d.weekMinSun && d.dayMin <= d.monthMin
        && d.weekMin <= d.lifeMin && d.weekMinSun <= d.lifeMin && d.monthMin <= d.lifeMin
        && d.updatedAt == request.time;                          // server time: can't be in the future
    }
    // Garden leaderboards (optional, v1.16): produce ever harvested and plants harvested, whole numbers with a ceiling.
    function validGardenTotals(d) {
      return (!('produce' in d) || (d.produce is int && d.produce >= 0 && d.produce <= 10000000))
          && (!('harvests' in d) || (d.harvests is int && d.harvests >= 0 && d.harvests <= 1000000));
    }
    // An all-time total that is new on the document (an older document, or an older app that stopped sending it)
    // may take any value under its ceiling; while it stays on the document it never goes down and grows at most
    // perMin per minute since the last write (plus one 4-hour session), plus slack. Like lifeMin's first upload,
    // this is a self-reported stat: dropping and re-adding the field resets the bound (accepted; see the notes).
    function growsTotal(n, o, f, perMin, slack, room) {
      return !(f in n) || !(f in o) || (n[f] >= o[f] && n[f] - o[f] <= room * perMin + slack);
    }
    function createLimits() { return true; }                  // first upload may include past history
    // Minutes since this document was last written (server clock).
    function elapsedMin() { return (request.time.toMillis() - resource.data.updatedAt.toMillis()) / 60000; }
    // Within the same period a total can't go down, and can't grow by more than the real time
    // that has passed since the last write plus one 4-hour session. A new period starts from 0.
    // (n, o and room — minutes since the last write + one 4-hour session — are computed once per request: the rules
    // engine allows 1,000 expressions per request, and recomputing them in every check went over it in v1.19)
    function grows(n, o, keyField, minField, room) {
      return (n[keyField] == o[keyField] && n[minField] >= o[minField] && n[minField] - o[minField] <= room)
          || (n[keyField] != o[keyField] && n[minField] <= room);
    }
    function updateLimits() {
      let n = request.resource.data;
      let o = resource.data;
      let room = elapsedMin() + 240;
      return grows(n, o, 'dayKey', 'dayMin', room) && grows(n, o, 'weekKey', 'weekMin', room) && grows(n, o, 'weekKeySun', 'weekMinSun', room) && grows(n, o, 'monthKey', 'monthMin', room)
        && n.lifeMin >= o.lifeMin && n.lifeMin - o.lifeMin <= room
        && growsTotal(n, o, 'produce', 2.0, 0, room) && growsTotal(n, o, 'harvests', 0.034, 2, room);   // ≤ 2 produce per minute of focus; a harvest per ~30 minutes (v1.16)
    }

    // ---------------- v1.19: ranks and streaks (a document of their own) ----------------
    // rankStats/{uid}: the look shown on the boards, the global flag, this season's counted minutes and last season's
    // peak, the current and best streak with the last day the goal was met, and the account's creation time. Kept out
    // of publicStats so neither document's checks come near the rules engine's 1,000-expression budget per request.
    match /rankStats/{uid} {
      allow get: if signedIn() && (me() == uid || ((resource.data.global == true || isFriend(uid)) && !blockedBy(uid)));

      let n = request.resource.data;
      let o = resource.data;

    // ---------------- v1.19: seasons (ranks) and streaks ----------------
    // A season is the current calendar month in UTC (the server clock). Counted minutes allow at most 14 h (840 min) a
    // UTC day, so they can't exceed 840 × the day of the month; within a season they never go down and grow by at most
    // the real time since the last write + 4 h; a new season starts from that bound. prevPeak (last season's peak rank,
    // which sets the placement floor) is 0 on a new document or a new field, stays fixed within a season and, when the
    // season changes, can't exceed the rank of the minutes the document held.
    function seasonKeyNow() { return string(request.time.year()) + '-' + (request.time.month() < 10 ? '0' : '') + string(request.time.month()); }
    // the rank index of counted minutes, as in the app (Bronze III 0 … Diamond I 14, Master 15, Grandmaster 16)
    function rankOf(m) {
      return (m >= 200 ? 1 : 0) + (m >= 400 ? 1 : 0) + (m >= 600 ? 1 : 0) + (m >= 900 ? 1 : 0) + (m >= 1200 ? 1 : 0) + (m >= 1500 ? 1 : 0)
        + (m >= 2000 ? 1 : 0) + (m >= 2500 ? 1 : 0) + (m >= 3000 ? 1 : 0) + (m >= 3600 ? 1 : 0) + (m >= 4200 ? 1 : 0) + (m >= 4800 ? 1 : 0)
        + (m >= 5600 ? 1 : 0) + (m >= 6400 ? 1 : 0) + (m >= 7200 ? 1 : 0) + (m >= 10800 ? 1 : 0);
    }
    function validSeason(d) {
      return (!('seasonKey' in d) && !('seasonMin' in d) && !('prevPeak' in d))
        || (d.seasonKey == seasonKeyNow() && d.seasonMin is int && d.seasonMin >= 0 && d.seasonMin <= request.time.day() * 840
            && d.prevPeak is int && d.prevPeak >= 0 && d.prevPeak <= 16);

    function seasonGrows(n, o, room) {
      return !('seasonKey' in n)
        || (!('seasonKey' in o) && n.prevPeak == 0)
        || (n.seasonKey == o.seasonKey && n.seasonMin >= o.seasonMin && n.seasonMin - o.seasonMin <= room && n.prevPeak == o.prevPeak)
        || (n.seasonKey != o.seasonKey && n.seasonMin <= room && n.prevPeak <= rankOf(o.seasonMin));
    }
    // Streaks: whole numbers, best ≥ current, best no longer than the account is old (joined = the account's creation

    // The current streak may jump up to the best (a device that catches up). Self-reported: the first publish is only
    // bounded by the account's age (see the report).
    function validStreak(d) {
      return (!('streak' in d) && !('bestStreak' in d) && !('streakDay' in d) && !('joined' in d))

            && d.bestStreak <= (request.time.toMillis() - d.joined) / 86400000 + 2
            && d.streakDay is string && (d.streakDay == '' || dayKeyOk(d.streakDay)));
    }
    function streakGrows(n, o, room) {

      return !('streak' in n) || !('streak' in o)
        || (n.joined == o.joined && n.bestStreak >= o.bestStreak && n.bestStreak - o.bestStreak <= days);   // (the current streak is bounded by the best)
    }

    // Monthly raid HP (v1.14.3, the same table as the app). Up to October 2026: 600 per member, at least 1,800.
    // From November 2026 each month has a boss with an HP range [for 1 member, for 30 members], in a 12-month cycle
    // starting in November; HP = min + (max - min) × (members - 1) / 29, rounded to the nearest 100.
    function raidRange(mk) {
      let i = ((int(mk[0:4]) * 12 + int(mk[5:7]) - 24323) % 12 + 12) % 12;
      return [[7000, 9300], [7500, 10000], [5000, 6000], [6500, 8500], [8000, 10000], [5000, 6000],
              [7000, 9300], [6500, 8500], [5000, 6000], [6000, 8000], [8500, 10000], [5500, 7500]][i];
    }
    // v1.18: the range is looked up once (`let`), so a clan write stays well inside the rules engine's 1,000-expression
    // budget — from November 2026 the first version evaluated the 12-month table three times per call and clan
    // creation (a six-document batch) tripped the budget.
    function raidHPFor(mk, members) {
      let r = raidRange(mk);
      let m = members > 30 ? 30 : (members < 1 ? 1 : members);
      return mk < '2026-11'
        ? (members * 600 > 1800 ? members * 600 : 1800)
        : math.round((r[0] * 29 + (r[1] - r[0]) * (m - 1)) / 2900.0) * 100;
    }

    // A day key ('YYYY-MM-DD') or month key ('YYYY-MM') that isn't ahead of the server's calendar (one day / one month of
    // leeway for time zones). A far-future key would freeze the clan's counting for everyone, so it's refused.
    function dayKeyOk(k) {
      return k is string && k.matches('^20[0-9]{2}-(0[1-9]|1[0-2])-(0[1-9]|[12][0-9]|3[01])$')
        && timestamp.date(int(k[0:4]), int(k[5:7]), int(k[8:10])) <= request.time + duration.value(1, 'd');   // at most a day ahead (also on the last day of a month — v1.19)
    }
    function monthKeyOk(k) {
      return k is string && k.matches('^20[0-9]{2}-(0[1-9]|1[0-2])$')
        && int(k[0:4]) * 12 + int(k[5:7]) <= request.time.year() * 12 + request.time.month() + 1;

          || (k.hasOnly(['owned', 'spent', 'lastBuy', 'updatedAt']) && clanBuy(cid, n, o))
          || (k.hasOnly(['quests', 'tq', 'updatedAt']) && clanQuest(cid, n, o))

          || (k.hasOnly(['weekGroups', 'weekKey', 'weekMin', 'gday', 'gstreak', 'lastLive', 'updatedAt']) && clanGroup(cid, n, o))

    // Bonus Clan Points (v1.18): exactly what my member row adds to today's count (at most 6 a day, see memberBonus).
    function clanBonus(cid, n, o) {
      let mo = get(memberPath(cid, me())).data;
      let mn = getAfter(memberPath(cid, me())).data;
      let had = mn.bday == mo.get('bday', '') ? mo.get('bcp', 0) : 0;
      return isMember(cid) && n.bonus is int && n.bonus - o.get('bonus', 0) == mn.bcp - had && n.bonus > o.get('bonus', 0);
    }
    // A member's completed focus adds to the clan, exactly as much as to their own contribution.
    function clanFocus(cid, n, o) {
      let d = n.xp - o.xp;
      return isMember(cid) && n.xp is int && d > 0 && d <= 1440 && levelOk(n.xp, n.level)
        && getAfter(memberPath(cid, me())).data.contrib - get(memberPath(cid, me())).data.contrib == d
        && ((n.weekKey == o.weekKey && n.weekMin == o.weekMin + d && n.weekGroups == o.weekGroups)
            || (dayKeyOk(n.weekKey) && n.weekKey > o.weekKey && n.weekMin == d && n.weekGroups == 0))
        && ((n.monthKey == o.monthKey && n.monthMin == o.monthMin + d && n.raidHP == o.raidHP)
            || (monthKeyOk(n.monthKey) && n.monthKey > o.monthKey && n.monthMin == d && n.raidHP == raidHPFor(n.monthKey, n.members)));
    }
    // Member count: +1 when someone joins (themselves in an open clan, or accepted by a leader/officer), −1 when someone leaves
    // or is removed. lastMember names that person, and their member row must really appear or disappear in the same write.
    function clanCount(cid, n, o) {
      let who = n.lastMember;
      return n.members is int && n.members >= 0 && n.members <= 30 && who is string && (
        (n.members == o.members + 1 && !exists(memberPath(cid, who)) && existsAfter(memberPath(cid, who))
          && ((who == me() && o.joinMode == 'open') || (who != me() && isOfficer(cid))))
        || (n.members == o.members - 1 && exists(memberPath(cid, who)) && !existsAfter(memberPath(cid, who))
          && ((who == me() && isMember(cid)) || (who != me() && isOfficer(cid))))
      );
    }
    // Join mode and the clan's look: the leader (the look also by officers when the leader allows it). Only owned looks.
    function clanSettings(cid, n, k) {
      return n.joinMode in ['approval', 'open']
        && lookOk(n, 'emblem', 'ce_tomato') && lookOk(n, 'banner', 'cb_default') && lookOk(n, 'theme', 'ct_default') && lookOk(n, 'frame', 'cf_none')
        && (isLeader(cid) || (!k.hasAny(['joinMode']) && isOfficer(cid) && get(infoPath(cid)).data.officerShop == true));
    }
    // Clan shop: one item at a time, at its price, if the clan level allows it and the points cover it.
    function clanBuy(cid, n, o) {
      let key = n.lastBuy;
      let item = shopItem(key);
      return item != null && n.owned.diff(o.owned).affectedKeys() == [key].toSet() && !(key in o.owned) && n.owned[key] == true
        && n.spent == o.spent + item[0] && n.level >= item[1] && n.spent <= earned(n)
        && (isLeader(cid) || (isOfficer(cid) && get(infoPath(cid)).data.officerShop == true));
    }
    // Weekly quest: claimed once per week, when its goal is met.
    function clanQuest(cid, n, o) {
      let goal = n.members * 300 < 3000 ? n.members * 300 : 3000;
      return isMember(cid) && n.tq == o.tq + 1
        && n.quests.diff(o.quests).affectedKeys().hasOnly([n.weekKey]) && !(n.weekKey in o.quests)
        && ((n.quests[n.weekKey] == 'min' && n.weekMin >= goal) || (n.quests[n.weekKey] == 'grp' && n.weekGroups >= 3));
    }
    // Monthly raid boss: defeated once per month, when the month's clan minutes reach its HP.
    function clanRaid(cid, n, o) {
      return isMember(cid) && n.tr == o.tr + 1
        && n.raids.diff(o.raids).affectedKeys().hasOnly([n.monthKey]) && !(n.monthKey in o.raids)
        && n.raids[n.monthKey] is string && n.raids[n.monthKey].matches('^(titan|leviathan|colossus|behemoth|wyrm|hydra|phantom|swarm|goblin|sloth|kraken|wizard|gremlin|tyrant|pumpkin)[+]?$')
        && (!n.raids[n.monthKey].matches('.*[+]$') || n.members >= 5)        // the rally bonus: 5+ members contributed (v1.14.3)
        && n.raidHP > 0 && n.monthMin >= n.raidHP;
    }
    // A live session with 2+ people: counted once (its live document flips "counted"), for the
    // weekly group-session quest and the clan's study streak.
    function clanGroup(cid, n, o) {
      let live = /databases/$(database)/documents/clans/$(cid)/live/$(n.lastLive);
      let other = getAfter(live).data.second;
      return isMember(cid) && n.lastLive is string && n.lastLive != o.lastLive
        && get(live).data.counted == false && getAfter(live).data.counted == true
        // two different members with a seat at that table: me and the person named in "second" (v1.14.3)
        && other is string && other != me()
        && exists(/databases/$(database)/documents/clans/$(cid)/live/$(n.lastLive)/people/$(me()))
        && exists(/databases/$(database)/documents/clans/$(cid)/live/$(n.lastLive)/people/$(other))
        && ((n.weekKey == o.weekKey && n.weekMin == o.weekMin && n.weekGroups == o.weekGroups + 1)
            || (dayKeyOk(n.weekKey) && n.weekKey > o.weekKey && n.weekMin == 0 && n.weekGroups == 1))     // the first group session of a new week
        && dayKeyOk(n.gday) && n.gstreak is int && n.gstreak >= 0 && n.gstreak <= o.gstreak + 1;
    }

    function validNewMember(cid, uid) {

      return d.keys().hasOnly(['name', 'role', 'joinedAt', 'contrib', 'weekKey', 'weekMin', 'lastAt', 'lastIds', 'avatar', 'color', 'aura', 'level', 'tier', 'shareNames', 'focusUntil', 'updatedAt'])
        && d.contrib == 0 && d.weekMin == 0 && d.lastIds.size() == 0                 // contribution starts at zero on joining
        && d.joinedAt == request.time && d.updatedAt == request.time
        && d.name is string && d.name.size() <= 20
        // one clan per user: their clanOf points here after this write, and pointed nowhere before
        && !exists(clanOfPath(uid)) && getAfter(clanOfPath(uid)).data.clan == cid
        && (exists(clanPath(cid)) ? (get(clanPath(cid)).data.members < 30) : true);
    }
    // My completed focus since I joined: grows by at most the real time that passed (+ one 4-hour session),
    // never shrinks, and the clan document gains exactly the same minutes in the same write.
    function memberFocus(cid, uid) {
      let n = request.resource.data;
      let o = resource.data;
      let elapsed = (request.time.toMillis() - o.updatedAt.toMillis()) / 60000;
      return uid == me() && isMember(cid)
        && changed(['contrib', 'weekKey', 'weekMin', 'moKey', 'moMin', 'lastAt', 'lastIds', 'updatedAt'])
        && n.contrib > o.contrib && n.contrib - o.contrib <= elapsed + 240
        // this month's raid hits (v1.14.3; apps before it leave these two fields alone)
        && ((n.get('moKey', '') == o.get('moKey', '') && n.get('moMin', 0) == o.get('moMin', 0))
            || (n.moKey == getAfter(clanPath(cid)).data.monthKey && n.moMin is int
                && ((n.moKey == o.get('moKey', '') && n.moMin == o.get('moMin', 0) + (n.contrib - o.contrib))
                    || (n.moKey != o.get('moKey', '') && n.moMin == n.contrib - o.contrib))))
        && getAfter(clanPath(cid)).data.xp - get(clanPath(cid)).data.xp == n.contrib - o.contrib
        && ((n.weekKey == o.weekKey && n.weekMin == o.weekMin + (n.contrib - o.contrib)) || (n.weekKey > o.weekKey && n.weekMin == n.contrib - o.contrib))
        && n.lastIds is list && n.lastIds.size() <= 12
        && n.lastAt is int && n.lastAt <= request.time.toMillis() + 600000      // device clocks can be a little ahead
        && n.updatedAt == request.time;
    }
    // Today's bonus Clan Points from clan sessions (v1.18): the day can't run ahead of the calendar or go back, the count
    // only grows within a day and stays at most 6, and the clan's bonus total grows by exactly the same amount.
    function memberBonus(cid, uid) {
      let n = request.resource.data;
      let o = resource.data;
      let had = n.bday == o.get('bday', '') ? o.get('bcp', 0) : 0;
      let y = request.time - duration.value(1, 'd');
      return uid == me() && isMember(cid) && changed(['bday', 'bcp', 'updatedAt'])
        && dayKeyOk(n.bday) && n.bday >= o.get('bday', '') && n.bcp is int && n.bcp > had && n.bcp <= 6
        && int(n.bday[0:4]) * 10000 + int(n.bday[5:7]) * 100 + int(n.bday[8:10]) >= y.year() * 10000 + y.month() * 100 + y.day()   // today or yesterday only
        && o.joinedAt < request.time - duration.value(1, 'd')                                                        // not in the first day of membership
        && getAfter(clanPath(cid)).data.get('bonus', 0) - get(clanPath(cid)).data.get('bonus', 0) == n.bcp - had
        && n.updatedAt == request.time;
    }
    // My look in the member list (picture, name colour, aura, level) and whether others see my session names.
    function memberLook(cid, uid) {
      let n = request.resource.data;
      return uid == me() && isMember(cid) && changed(['avatar', 'color', 'aura', 'level', 'tier', 'shareNames', 'focusUntil'])
        && n.avatar is string && n.avatar.size() <= 30 && n.color is string && n.color.size() <= 30 && n.aura is string && n.aura.size() <= 30
        && n.level is int && n.level >= 1 && n.level <= 1000 && n.tier is string && n.tier.size() <= 20
        && n.shareNames is bool && n.focusUntil is int && n.focusUntil <= request.time.toMillis() + 4 * 3600000;
    }
    // Roles: only the leader promotes, demotes and hands over leadership.
    function memberRole(cid, uid) {
      return isLeader(cid) && changed(['role'])
        && request.resource.data.role in ['leader', 'officer', 'member']
        && (uid != me() || (request.resource.data.role != 'leader' && getAfter(infoPath(cid)).data.leader != me()))   // stepping down = handing over
        // a new leader always comes with the private info pointing to them (transfer in one write)
        && (request.resource.data.role != 'leader' || getAfter(infoPath(cid)).data.leader == uid);
    }
    function validReaction() {
      return request.resource.data.keys().hasOnly(['from', 'emoji', 'at'])
        && request.resource.data.from == me() && request.resource.data.emoji in ['🔥', '👏', '💪', '☕', '👋']
        && request.resource.data.at == request.time;
    }
    function validStudySession(d) {
      return d.keys().hasOnly(['title', 'start', 'pattern', 'repeat', 'days', 'tag', 'max', 'creator', 'creatorName', 'cancelled', 'rsvp', 'mode', 'createdAt', 'updatedAt'])
        && (!('mode' in d) || d.mode in ['together', 'synced'])          // v1.14.2; no mode = Synced
        && d.title is string && d.title.size() >= 2 && d.title.size() <= 40 && cleanText(d.title)
        && d.start is int && d.pattern is map && d.pattern.keys().hasOnly(['focus', 'short', 'rounds'])
        && d.pattern.focus is int && d.pattern.focus >= 5 && d.pattern.focus <= 120
        && d.pattern.short is int && d.pattern.short >= 1 && d.pattern.short <= 30
        && d.pattern.rounds is int && d.pattern.rounds >= 1 && d.pattern.rounds <= 8
        && d.repeat in ['none', 'daily', 'weekdays', 'weekly'] && d.days is list && d.days.size() <= 7
        && d.tag is string && d.tag.size() <= 30 && cleanText(d.tag)
        && d.max is int && d.max >= 2 && d.max <= 30
        && d.cancelled is bool && d.rsvp is map && d.rsvp.size() <= 30
        && d.creatorName is string && d.creatorName.size() <= 20 && d.updatedAt == request.time;
    }
    function validLive(d) {
      return d.keys().hasOnly(['title', 'host', 'hostName', 'pattern', 'startAt', 'pausedAt', 'pauseTotal', 'shift', 'open', 'counted', 'second', 'sid', 'mode', 'createdAt', 'endedAt', 'updatedAt'])
        && (!('mode' in d) || d.mode in ['together', 'synced'])          // v1.14.2; no mode = Synced
        && (!('second' in d) || d.second is string)                       // v1.14.3: the second person when counted as a group session
        && d.title is string && d.title.size() >= 2 && d.title.size() <= 40 && cleanText(d.title)
        && d.pattern is map && d.pattern.focus is int && d.pattern.focus >= 5 && d.pattern.focus <= 120
        && d.pattern.short is int && d.pattern.short >= 1 && d.pattern.short <= 30 && d.pattern.rounds is int && d.pattern.rounds >= 1 && d.pattern.rounds <= 8
        && d.startAt is timestamp && d.pausedAt is int && d.pausedAt >= 0 && d.endedAt is int && d.pauseTotal is int && d.pauseTotal >= 0 && d.shift is int && d.shift >= 0
        && d.open is bool && d.counted is bool && d.sid is string && d.updatedAt == request.time;
    }

    match /clanNames/{name} {
      allow get: if signedIn();                          // "is this name taken?"
      allow list: if false;
      allow create: if signedIn() && request.resource.data.keys().hasOnly(['clan'])
        && getAfter(clanPath(request.resource.data.clan)).data.nameLower == name && !exists(clanPath(request.resource.data.clan))
        && getAfter(memberPath(request.resource.data.clan, me())).data.role == 'leader';
      allow delete: if signedIn() && isLeader(resource.data.clan) && !existsAfter(clanPath(resource.data.clan))
        || (isMember(resource.data.clan) && !existsAfter(clanPath(resource.data.clan)));
    }
    match /clanCodes/{code} {
      allow get: if signedIn();                          // by code only: nobody can list codes
      allow list: if false;
      allow create: if signedIn() && request.resource.data.keys().hasOnly(['clan'])
        && getAfter(infoPath(request.resource.data.clan)).data.code == code
        && getAfter(memberPath(request.resource.data.clan, me())).data.role == 'leader';
      allow delete: if signedIn() && (isLeader(resource.data.clan) || (isMember(resource.data.clan) && !existsAfter(clanPath(resource.data.clan))));
    }
    match /clanOf/{uid} {
      allow get: if signedIn() && uid == me();
      allow list: if false;
      allow create: if signedIn() && request.resource.data.keys().hasOnly(['clan', 'at']) && request.resource.data.at == request.time
        && existsAfter(memberPath(request.resource.data.clan, uid))
        && (uid == me() || (isOfficer(request.resource.data.clan) && exists(/databases/$(database)/documents/clans/$(request.resource.data.clan)/requests/$(uid))));
      allow delete: if signedIn() && !existsAfter(memberPath(resource.data.clan, uid))                  // only when the member row goes too
        && (uid == me() || isLeader(resource.data.clan) || (isOfficer(resource.data.clan) && get(memberPath(resource.data.clan, uid)).data.role == 'member'));
    }

    // Everything else is closed.
  }
}
```
