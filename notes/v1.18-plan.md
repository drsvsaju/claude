## PHASE 1 — Bug fixes (do these first)

### 1a. Recently used presets are broken
The "Recently used" preset chips on the timer screen barely work (screenshot shows a chip like `● Physics - Mechanical 25/5 ☆` with a Clear button). Fix it fully:
- Clicking a chip must reliably load that preset (name, focus/break lengths, subject/colour) into the timer every time.
- Starring must toggle favourite and persist; favourites stay pinned at the front.
- No duplicates: re-using a preset moves it to the front instead of adding a copy.
- Cap the list (e.g. 6 recent + favourites).
- "Clear" removes recents but keeps favourites (confirm before clearing).
- Must sync correctly between localStorage and Firestore with no race conditions (cache-first load must not overwrite newer cloud data, and vice versa). Find the root cause, don't patch around it.
- Must not break if a preset was deleted or renamed.
- Write tests covering click-to-load, star, dedupe, clear, sync, and deleted-preset cases.

### 1b. Challenge join cap
Right now a user can join unlimited challenges they are invited to, which makes coins too easy.
- A user can be in **their own challenge + at most 1 joined challenge per week** (so max 2 active challenges per week).
- If they're at the cap, the invite shows "You're already in a challenge this week" and the Join button is disabled.
- Enforce it in the client **and** in Firestore rules (or with a per-user weekly counter doc the rules check), so it can't be bypassed from the console.
- Existing users already over the cap this week keep their current challenges, but can't join more until next week.

## PHASE 2 — Social hub: new Friends tab with Study Sessions

### 2a. Redesign the Friends tab
Split it into three sub-tabs with a clean segmented control:
**Friends · Study sessions · Challenges**
- **Friends:** friend list with online/focusing status, add friend, requests, kudos/nudges (keep existing features working). Show a "Studying now" badge + "Ask to join" button on friends who are hosting an active session.
- **Study sessions:** create a session, see active/planned sessions you can join (friends' sessions + public ones), your session history.
- **Challenges:** move the existing challenges UI here, with the new cap visible ("1/1 joined this week").
- Make sure everything in the old Friends tab still works after the move. Fix any existing friends-tab bugs you find along the way and list them in the report.

### 2b. Public study sessions without a clan
Anyone can host a study session, no clan required.
- Host chooses: name, mode (**Focus Together** = everyone runs their own timer at a shared table, default; or **Synced timer** = one shared timer), planned or start now, visibility (**Friends only** / **Invite link** / **Public**), max participants (e.g. 2–10).
- Reuse the existing clan session engine where possible instead of building a second one. Clan sessions keep working exactly as before.
- Live participant list with presence (avatar, frame, aura, current status: focusing/break/idle). Use a heartbeat so people who close the tab drop out after ~1–2 min.
- Host can kick, end the session, or hand over host. If the host leaves, host passes to the longest-present participant; if everyone leaves, the session ends.
- Sessions auto-expire (e.g. after 6 hours or when empty) so Firestore doesn't fill with dead sessions.

### 2c. Joining a friend's session (ask to enter)
- If you're friends with someone hosting an active session, you can tap **Ask to join**.
- The host gets an in-app popup: "**[username] wants to join your session** — Allow / Decline". Make it non-intrusive during focus (small toast/card, doesn't pause the timer, doesn't play a loud sound if they muted).
- Requester sees "Waiting for [host]…" with a cancel button; request times out after ~2 minutes.
- Rate-limit requests (no spamming the same host).
- Firestore rules: a user can only create a request for themselves; only the host can approve/decline; only approved users can write presence into a non-public session.

### 2d. Invites
- **Friends:** invite directly in the app from the session screen → friend gets an in-app invite (inbox + toast) with Join / Ignore.
- **Strangers:** shareable invite link (random code, like clan invite codes). Opening the link while logged out → sign up / log in → lands in the session. Host can regenerate or disable the link.
- Copy button must work on all browsers (use the same fixed copy helper from earlier versions).

## PHASE 3 — Rewards for studying together

### 3a. Clan session milestones (clan sessions should reward more)
Clan study sessions give more than normal sessions to keep clans worthwhile:
- Bonus Clan Points + a small coin bonus for focus done inside a clan session.
- **Clan session milestones** for total hours studied in clan sessions (per user), e.g. 5h / 15h / 40h / 100h / 250h. Rewards are **clan-exclusive**: clan seeds (unique species only obtainable this way), clan icons/stamps, a clan banner frame, a clan-coloured aura, and a title like "Clan Scholar".
- Show milestone progress on the clan page and the profile.

### 3b. Group study achievements
Add achievements for studying with others (only count time where **2+ people were actually present and focusing** at the same time, verified by overlapping presence):
- First session with a new person → coins (cap: rewards for max ~3 new people per day).
- Host your first session → profile badge.
- X hours in sessions with 2+ people (e.g. 1h, 10h, 50h, 100h) → cosmetics (aura, frame, avatar, room item).
- Study with 5 / 15 / 30 different people → "Study Buddy" / "Social Scholar" titles + garden decoration.
- Complete a full synced-timer session with 3+ people → special timer style.
- Add 10–15 more of your own ideas in the same spirit. Mix of coins, garden rewards (seeds, decorations, pet eggs), PFPs, auras, frames, titles.

### 3c. More achievements in general
Expand the achievement list with a focus on garden and long-term play: first Giant harvest, harvest every species of a rarity, all pet slots filled, 1/2/5 star harvest collections, focusing in every season/weather mutation, weekend festival participation, etc. Rewards: produce, seeds, garden cosmetics, auras, PFPs. Make the achievements page sortable (category, completed, closest to done) with progress bars.
