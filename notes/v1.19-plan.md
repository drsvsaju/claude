## 1. Ranks (seasonal, based on study hours)

Levels already exist (XP, 9 tiers Novice→Legend) and show **lifetime** progress. Ranks are different: they show **how much you study right now**, reset each season, so new users can compete with old ones and long-term users always have a goal.

### How it works
- **Season = one calendar month** (aligned with the existing monthly questline / reward track).
- Rank is based on **focus hours logged this season** (completed focus blocks only, including Finish-early blocks that count under existing rules).
- **Fixed hour thresholds**, not "top X%", so everyone can rank up without someone else ranking down, and it's simpler to secure:

| Rank | Season hours |
|---|---|
| Bronze | 0–10 |
| Silver | 10–25 |
| Gold | 25–50 |
| Platinum | 50–80 |
| Diamond | 80–120 |
| Master | 120–180 |
| Grandmaster | 180+ |

- Each rank from Bronze to Diamond has **3 divisions** (III → II → I), splitting its hour range evenly, so there's always a small next step. Master and Grandmaster have no divisions.
- If you think these numbers are off for students doing 3–6 hours a day, adjust them and explain why in the report.

### Season reset
- **Soft reset**: at the start of a new month, the rank display restarts from the new month's hours, but users start with a small **placement boost** based on last season's peak rank (e.g. Diamond last month → starts at Silver I instead of Bronze III). Keep it simple and document the exact rule.

### Rewards
- **End-of-season reward** based on the **peak rank** reached that season: coins + a season badge (e.g. "Nov 2026 · Diamond") shown in the profile's trophy shelf. Claimed once per season, never twice.
- **First time ever** reaching each rank: a one-time cosmetic (rank-coloured frame / aura / avatar ring / Pomeo room item). Grandmaster gets an animated frame.
- Rank-up celebration: small toast during focus, full celebration after the focus block ends (same pattern as streak milestones).

### Where it shows
- Rank badge (small icon + name) on the profile card, friend rows, leaderboard rows, session participant lists, clan member list.
- Progress bar to next division on the Timer screen (compact, hidden in True Minimalist mode) and profile.
- New **Ranks** leaderboard view (Friends / Global): sorted by season hours, showing rank badges. Reuse the existing leaderboard v2 UI (podium, rank arrows).

### Anti-cheat
- Season hours come only from completed focus blocks already logged by the app. Cap counted hours per UTC day (e.g. 14h) so a broken or tampered client can't jump to Grandmaster.
- Firestore rules: the published season hours can only increase within a season, by no more than a sane amount per write, and only for the current month key. No one can write another user's rank.
