# Visual consistency audit (v1.20 → v2.0)

A synthesis of the two stylesheet maps (`notes/v2.0-codemap/01-css-a.md` for lines 9–1999 and `02-css-b.md` for
2001–3793), which hold the full tables, selectors and line numbers. Counts are for the whole stylesheet unless a slice
is named.

## Tokens today
- **Colour roles (10):** `--bg --surface --text --muted --line --accent --accent-soft --heat0 --danger --warn`, plus
  `--on-accent`, which has no CSS default (it falls back to `#fff`).
- **Themes** are JS palettes (`SKINS`): `applyTheme()` writes nine of those inline on `<html>`. `--danger`, `--warn`,
  radii, shadows and the glass tokens never follow a theme.
- **v1.7 scale tokens** exist (`--sp-1..6`, `--r-sm/md/lg/pill`, `--sh-1/2`, `--fs-xs..xl`, `--card-pad`) but about
  5% of declarations use them: 12 of 171 radii, 14 of 270 font sizes and 4 of 41 shadows in the second half; 2 of 658
  spacing declarations in the first half.
- **Motion:** three easings (`--ease`, `--spring`, `--spring-soft`), no duration tokens.

## Contrast measured on the default palettes
- White on the accent: **3.91:1** light, **2.52:1** default dark (primary button, active segment, pills).
- Accent as text on the card: 3.91:1 light. Warning text on white: 3.46:1. Fixed medal / mutation / delta colours:
  3.0–3.6:1.
- Control boundaries (`--line` on `--surface`): 1.26:1, so inputs, the switch's off track and the timer ring track
  are close to invisible for low vision.
- Muted text passes (5.56 light, 5.60 dark); danger text passes in light (5.10).

## Migration order
1. Add the token block as a superset; old names stay as aliases. Nothing visible changes.
2. Shared base in Phase 1: buttons, cards, fields, segmented controls, dialogs, toasts, focus rings, the touch-target
   block (extended to the new roles).
3. Per screen in Phase 3, with that screen's suites and screenshots: literals → tokens, look-alikes → the one
   component, appended fix-up blocks folded into their primary rules.
4. Not mechanical (needs eyes): the glass `:is()` lists (specificity), duplicated keyframes (`dlgIn`, `drift`,
   `twinkle`, `bossIdle`…: the later one wins file-wide and some names are test contracts), the runtime stylesheet
   from `rewardCSS()`, garden and room scene art (kept as art, not tokenised).
